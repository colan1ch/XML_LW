# Курс «Программирование сетевых приложений»

Учебный репозиторий с лабораторными работами по веб-разработке и сетевому взаимодействию. В проекте представлены клиентские приложения на HTML/CSS/JavaScript, работа с npm-модулями, REST API на NestJS и интерфейсы, взаимодействующие с сервером через `XMLHttpRequest` и `fetch`.

## Стек технологий

- **HTML5, CSS3, JavaScript** — клиентская часть и интерактивные интерфейсы;
- **Bootstrap 5.3.5** — стилизация и компоненты интерфейса в лабораторных работах №3, №5 и №6;
- **Node.js и npm** — управление зависимостями и запуск JavaScript-проектов;
- **Vite 6.3.5** — dev-сервер и сборка лабораторной работы №6;
- **TypeScript** — серверная часть лабораторной работы №4;
- **NestJS 11** — REST API, контроллеры, сервисы, DTO и модули;
- **Swagger / OpenAPI** — документация API лабораторной работы №4;
- **XMLHttpRequest и Fetch API** — обмен данными между клиентом и сервером;
- **JSON и файловое хранение** — исходные данные и хранилище записей API;
- **Jest и Supertest** — инструменты тестирования NestJS-проекта.

## Установка и запуск

### Лабораторные работы №1–2

Откройте `index.html` через Live Server или другой локальный статический сервер:

```text
lab1/index.html
lab2/index.html
```

### Лабораторная работа №3

Установите Bootstrap и запустите каталог через Live Server:

```bash
cd lab3
npm install
```

Затем откройте `index.html` через Live Server.

### Лабораторная работа №4

Установите зависимости NestJS и запустите сервер:

```bash
cd lab4/example-nestjs
npm install
npm run start
```

API будет доступен на `http://localhost:3000`, документация Swagger — на `http://localhost:3000/api`.

Основные маршруты API:

```text
GET    /stocks
GET    /stocks/:id
POST   /stocks
PUT    /stocks/:id
PATCH  /stocks/:id
DELETE /stocks/:id
```

### Лабораторная работа №5

```bash
cd lab5
npm install
```

После установки откройте `index.html` через Live Server. Для работы клиентской части должен быть запущен API из лабораторной работы №4 на порту `3000`.

### Лабораторная работа №6

```bash
cd lab6
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
npm run preview
```

Лабораторная работа №6 также обращается к API на `http://localhost:3000`.
